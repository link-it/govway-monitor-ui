# govway-monitor-ui

## Gestione Dipendenze

All'interno della directory `repository.m2` sono raccolte tutte le dipendenze necessarie per i progetti.
Il repository e' condiviso per fare in modo che ogni progetto utilizzi le versioni sanificate delle proprie dipendenze.

## Compilazione delle librerie

Ogni libreria ha il suo README con le istruzioni per la compilazione, l'ordine deve essere il seguente:

- jsf-api-1.2_15-06
- jsf-impl-1.2_15-06
- jsf-facelets-1.1.15
- richfaces-3.3.4.Final
